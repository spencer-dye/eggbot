# `@eggbot/agent`

Provider-neutral decision-engine contracts. Engines receive one normalized `LeagueSnapshot`, an explicit managed-team ID, typed `LeagueAnalytics`, and optionally the exact `FootballIntelligenceSnapshot`. They return a `DecisionProposal`, not host audit metadata, and never receive credentials or platform executors.

`runDecisionEngine` validates context coherence, engine identity, proposal structure, league/team scope, and lineup scoring period. Supplied football intelligence must match the league scoring period and the exact projections retained by analytics. Untrusted actions are rebuilt from allowlisted fields and their identifiers are parsed through the core branded-ID constructors, so unknown fields are discarded. The application injects the clock plus decision- and action-ID factories; generated action IDs must be unique. A successful run returns a `DecisionRun` associating the resulting `FantasyDecision` with its exact source snapshot, analytics, optional football-intelligence input, managed team, engine identity/version, and execution window.
