# `@eggbot/scheduler`

Application-orchestration scheduling and recovery primitives. Fantasy logic does not belong here.

`RecoverableScheduler` runs one-time and interval jobs with durable `JobState`, in-process overlap prevention, cancellation, and recovery of jobs interrupted while marked `running`. It copies and freezes trigger/retry configuration at registration and rejects duplicate or durable-trigger-conflicting registrations with `SchedulerConflictError`. Cancellation persists a generation-advancing tombstone before removing the registration; a running callback that ignores abort cannot overwrite it, and startup registration does not revive canceled jobs. Job functions are deliberately not serialized; applications re-register them at startup and must make them idempotent because crash recovery is at-least-once. `StorageJobStateStore` persists state through `@eggbot/storage`.

`runWithRetry` provides bounded exponential backoff, requires an explicit error classifier, supports cancellation, and reports every failed attempt. Never classify an `execution-uncertain` mutation as retryable: reconcile provider state first. The included scheduler coordinates only one process. Multi-replica deployments must provide leader election or use an external scheduler and distributed lease system. Use stable logical job and operation IDs; recovered attempts need distinct attempt IDs but must not invent a new identity for the same intended league/team/scoring-period workflow.
