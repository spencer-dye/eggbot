# Examples

The credential-free composition example is the `@eggbot/cli` workspace in `apps/cli`. Run it with `pnpm cli`; use `pnpm cli yahoo help` for its opt-in Yahoo reads, local request previews, and guarded autonomous commands.

Concrete model and football-intelligence providers remain application-selected adapters. Trade support remains evaluation-only, and production storage, scheduling, and distributed coordination are application composition concerns documented in `docs/OPERATIONS.md`.
